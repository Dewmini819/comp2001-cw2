Profile Service API This project is a RESTful API developed for COMP2001 Coursework

2. It provides CRUD (Create, Read, Update, Delete) operations for managing user profile data.

The API is built using FastAPI and uses SQLite as the database for local development 

Technologies Used 
Python 3
FastAPI  
SQLAlchemy 
SQLite 
Uvicorn 
Swagger / OpenAPI

API Features 
- Create a profile
- Retrieve all profiles
- Retrieve a profile by ID
- Update a profile
- Delete a profile

 Notes
- SQLite is used for simplicity and local development.
- The database file is created automatically when the application runs.
- Swagger UI is used for testing all endpoints.
